# Employee Management System

A full-stack Employee Management System built with Java, Spring Boot, React, and MySQL.

## Technology Stack

- Backend: Java 25, Spring Boot, Maven, Spring Data JPA
- Frontend: React, Vite, JavaScript, Axios, CSS
- Database: MySQL 8.4
- Security: Spring Security, JWT
- Version Control: Git and GitHub

## Planned Features

- Employee CRUD operations
- Admin and employee roles
- Authentication and authorization
- Search, pagination, and form validation
- Responsive dashboard
- Testing and deployment

## Project Structure

- `backend/` — Spring Boot application
- `frontend/` — React application
- `docs/` — Project documentation
